# Research package and draft examples

| Example | Package and matching V0 | Use |
|---|---|---|
| Synthetic software fixture | [Package](research_package.json), [V0](v0.json) | Offline contract and writing tests; invented study data |
| Prepared real research case | [Package](../sprint2_demo/inputs/converted/research_package.json), [V0](../sprint2_demo/inputs/converted/v0.json) | The provisional research proposal displayed in Streamlit |

Keep each package paired with a draft using the same schema and package ID. The upload validator checks all six sections, claim coverage, evidence references and supporting citations; it does not confirm research correctness or grant human approval.

The editable research paper is [docs/research/draft_v0.md](../docs/research/draft_v0.md). The demo keeps its original snapshots and converted files for reproducibility. Changes to the editable paper do not automatically regenerate or approve that handover.
